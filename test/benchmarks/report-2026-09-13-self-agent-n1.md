## 观察（诚实记录）

1. **首过成功**：目标从 plan 到 completed 无需任何澄清或人工输入；
   行为证据（四向位移 + feel 延迟 + 编译验证）由目标层自动派生并全部通过。
2. **墙碰撞检查未执行**：oracle v1 只验证了位移与无报错——N1 清单中的
   "撞墙不穿透"需要 oracle 侧建墙+再测，本轮未包含（记录为未检查，不冒充通过）。
3. **环境摩擦**：端口冲突（9180 被 lghub 占用）导致一次 setup 失败——
   换端口即恢复；这类环境噪声计入摩擦日志而非任务失败。
4. 代理声明的完成以 workflow 状态为准——本产品中该状态本身携带证据门禁，
   oracle 复核是第二重独立验证，两者一致。

## 对正式对照的校准结论

- 单任务代理开销 ~6 次调用（走目标层）；若用纯原子工具预计 20+ 次。
- 预算建议（待正式对照采纳）：token 上限 200k/任务、工具调用 30 次/任务、
  墙钟 15 分钟/任务——本轮实际远低于此（校准用途）。
- oracle 需补齐：墙碰撞检查（建 StaticBody2D + 再位移断言）后方可开 12×3 对照。
